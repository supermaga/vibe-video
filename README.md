# vibe-video · 知识视频生成管线

输入提示词 → 自动分镜 → 扩写 → 配乐 → 渲染 → 成片，一条龙产出 1280×720 / 30fps 的科普动画视频。

## 亮点

- **确定性渲染** —— 单文件 Canvas / Remotion，同一输入永远产出同一画面
- **结构化分镜** —— 分镜可携带 `theme` 块切换视觉主题（浅色科普风 / 红金科技暗色），`sections` 块指定配乐幕结构
- **全流程可脚本化** —— headless Chrome 逐帧截图 + ffmpeg 合成，无人值守跑完整条管线

## 状态

管线全量可用（Remotion 移植完成，皮肤/运镜/特效/新场景/音效/透明导出齐备）。
